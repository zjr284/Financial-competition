## 录制与复核

录制前固定 Git 提交、Run ID、模型/提示词版本和文件 SHA-256。公开画面不显示密钥、私有路径、个人金融底稿或完整模型响应。实际 HTTP 不等于真实金融数据，合成资料即使走真实服务也始终标注“合成/非实测”。规则生成结果与云端新生成/固定响应重放分别说明。

C 当前可生成的素材：`record:live` 的核查、质量、财报与公告实际 HTTP 流程；`record:synthesis` 的产业链/备忘录固定协议流程；估值页的 TTM 三输入与上游计算。只选择其中必要片段，最终成片不把多个独立测试拼成一次未发生的业务运行。

真实三项重点题素材仍等待 B 的内部资料目录及团队金融复核。拿到资料后按同样界面录制，保留来源页和关键数字可读时间；真人标注独立完成并裁决后才填入留出集结果。由 A 核对运行、B 核对金融事实、C 核对画面与字幕，再完整播放成片并核查时长、大小、音轨及版本。平台上传与提交成功凭证另行由团队保存。
