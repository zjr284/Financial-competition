`video_storyboard.json` 固定九段讲稿，共 285 秒。画面是实际运行截图与说明卡，不把剪辑后的静态画面称为实时操作；机器配音持续标记，团队姓名暂用 A/B/C。此稿用于团队审阅，不能直接表示真人双标、独立留出评测或平台提交已完成。

公告段使用明确标注的合成联调截图；财报段读取 B 的真实归档；研报段使用真实来源与自编注错开发草稿。质量评分只称规则分。来源/代码版本和截取方式保存在私有素材清单，不把完整结果、金融底稿或原件提交 Git。

## 固定素材与截图

先 commit，保证截图来自干净版本。准备已恢复原件的私有运行副本及清单 JSON：

```json
[{"name":"finance","run_id":"run_EXISTING_FINANCE"}]
```

```powershell
# 使用实际 HTTP GET 读取归档，结果与 API 逐字段比对；拒绝脏工作区。
node web/tests/capture-archive.mjs PRIVATE_RUNTIME PRIVATE_INVENTORY_JSON NEW_PRIVATE_SCREENSHOT_DIR
```

脚本启动本机服务，不创建 Run、不提交人工决定；捕获 pageerror 和非 GET API 请求时失败。运行副本可以包含不同代码版本生成的旧 Run，读取归档不能称为用当前版本重新运行。准备目录 `PRIVATE_ASSETS/inputs/`，其中 `extraction.png` 来自 `test:disclosures` 的合成页面，另存真实归档截图 `finance.png`、`verification.png`、`quality.png`。不要以合成财务截图替换真实财报段。

## 配音与制作

Windows 需安装中文语音；调用系统自带语音，不上传讲稿到外部服务，也不修改注册表。通过 Windows PowerShell 5 的 WinRT 接口生成逐句 WAV（PowerShell 7 不提供此 WinRT 入口）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File demo/video_voice.ps1 `
  -Storyboard demo/video_storyboard.json -Output var/NEW_VOICE

# 额外制作依赖 Pillow；ffmpeg、ffprobe 须在 PATH。
python -m demo.build_video --storyboard demo/video_storyboard.json `
  --assets PRIVATE_ASSETS --voices var/NEW_VOICE --output var/NEW_VIDEO `
  --font C:/Windows/Fonts/msyh.ttc
```

所有输出拒绝覆盖旧目录。导出为 1920×1080、25fps、H.264/AAC MP4，内嵌逐句字幕，同时附 SRT、逐章 PNG 和输入/成片 SHA-256。讲稿超过 5 分钟、音轨过长、素材缺失、字幕过长或最终 MP4 无音轨/超限时明确失败。已有声音不足以适配时应删改讲稿，不把配音无限加速。

完成后检查 `build-proof.json`，查看逐章 PNG，解码完整 MP4，并完整播放审核配音、字幕和数字可读性。A 核对技术描述，B 核对金融表达，C 核对画面与版本。真人评测及真实公告展示尚未补齐时保留当前边界措辞；平台提交另由团队确认。审阅意见留在 PR，不再提供反馈 ZIP。
