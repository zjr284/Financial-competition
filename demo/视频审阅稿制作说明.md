# 4分45秒视频审阅稿

`video_storyboard.json` 固定九段讲稿，共 285 秒。画面是实际运行截图与说明卡，不把剪辑后的静态画面称为实时操作；团队姓名暂用 A/B/C。此稿用于团队审阅，不能直接表示真人双标、独立留出评测或平台提交已完成。

公告段现使用 C 已验收的两份真实质押公告、三条记录与来源框选；财报段读取 B 的真实归档；研报段使用真实来源与自编注错开发草稿。质量评分只称规则分。来源/代码版本和截取方式保存在私有素材清单，不把完整结果、金融底稿或原件提交 Git。v2 仅提供公告增量，不覆盖已通过修订的财务坐标与语义基线。

## 固定素材与截图

先 commit，保证截图来自干净版本。准备已恢复原件的私有运行副本及清单 JSON：

```json
[{"name":"finance","run_id":"run_EXISTING_FINANCE"}]
```

```powershell
# 使用实际 HTTP GET 读取归档，结果与 API 逐字段比对；拒绝脏工作区。
node web/tests/capture-archive.mjs PRIVATE_RUNTIME PRIVATE_INVENTORY_JSON NEW_PRIVATE_SCREENSHOT_DIR
```

脚本启动本机服务，不创建 Run、不提交人工决定；捕获 pageerror 和非 GET API 请求时失败。运行副本可以包含不同代码版本生成的旧 Run，读取归档不能称为用当前版本重新运行。准备目录 `PRIVATE_ASSETS/inputs/`：`extraction.png`、`extraction-july.png`、`extraction-end.png` 分别展示真实公告的数量字段、另一份公告及条件到期日；另存真实归档截图 `finance.png`、`verification.png`、`quality.png`。加一条 `{"name":"evidence","run_id":"run_EXISTING_VERIFICATION","source_button":"来源 1"}` 截取点击来源后的 PDF 哈希校验与框选画面，保存为 `evidence.png`。不要用合成截图替代真实案例。

素材必须是可读的视口画面；长网页截图先裁切相关区域并记录原始截图哈希，不能把整张长图缩成无法辨认的缩略图。原始字段与数字不得改绘。`assets` 可为每句讲稿指定不同截图，原件定位与核查结果无需挤在同一帧。

## 配音与制作

按用户偏好优先使用 Fish Audio；没有已连接服务或可用凭据时，交付无配音版供本人录音，不再默认使用 Windows 系统机器声音。本次选择无配音，不联网生成语音。旧 `video_voice.ps1` 仅保留为历史工具，未在本版执行。

```powershell
# 额外制作依赖 Pillow；ffmpeg、ffprobe 须在 PATH。
python -m demo.build_video --storyboard demo/video_storyboard.json `
  --assets PRIVATE_ASSETS --no-voice --output var/NEW_VIDEO `
  --font C:/Windows/Fonts/msyh.ttc
```

无配音模式不读取旧 WAV，不生成静音假配音轨；按 25fps 为每句分配窗口，27 个窗口合计 285 秒，同时输出 `配音时间表.md`、JSON、SRT。用户按每句起止时间录音即可；如先自行剪辑配音，可直接使用 SRT 对齐。窗口内允许自然留白。

有满意的 Fish Audio 或真人逐句 WAV 后，改用 `--voices PRIVATE_WAV_DIR`，文件名按章/句从 `00-00.wav` 到 `08-02.wav`。`--voices` 与 `--no-voice` 必选其一，不自动回退到系统语音。

所有输出拒绝覆盖旧目录。导出为 1920×1080、25fps、H.264 MP4；有声版另含 AAC，无配音版明确没有音轨。内嵌逐句字幕，同时附 SRT、逐章 PNG 和输入/成片 SHA-256。讲稿超过 5 分钟、音轨过长、素材缺失、字幕过长或成片超限时明确失败。有声版漏音轨、无声版意外混入音轨也会失败。

完成后检查 `build-proof.json`，查看逐章 PNG，解码完整 MP4，并完整播放审核字幕和数字可读性；补配音后再核对音画同步。A 核对技术描述，B 核对金融表达，C 核对画面与版本。真人评测仍未完成，不因真实公告段替换而改写此边界；平台提交另由团队确认。审阅意见留在 PR，不再提供反馈 ZIP。
