
公告按记录和字段逐项显示事件/证券代码/固定文档、原文写法、归一值、单位、后端核验状态和原因。未知引用不提供跳转；运行文档 ID 明示为元数据。原值为 null 时显示“未确定”，数值字符串 `0` 显示为零；大数和小数不经过 JavaScript Number 转换。缺失的到期日不会补成零或解除质押日期。

财报逐项显示 Fact ID、公司、金额/单位、起止期间、累计/单季/时点、合并/母公司、重述与复核状态。公共 Fact 没有 raw_value 字段，页面不补造原文写法，改为跳转固定原件。工具计算另列计算 ID、公式代码/名称、输入事实/上游计算 ID、参数、舍入和状态。缺失输入保留 ID 并提示，不能填入猜测金额。预警保留关联事实、来源、严重度及 supported/hypothesis/unresolved，不将提示写成已确认因果。

导出保留运行 ID、任务类型、API 版本、生成时间、任务/字段状态、原文/归一值、公司期间口径、证据、计算输入、警告和复核项。HTML 另保留完整 TaskResult；CSV 对公式前缀添加文本保护，完整机器读取以 JSON 为准。导出与页面都不修改后端核验状态。

离线资料明确 synthetic。实际 HTTP 只能证明服务返回，API 未声明其资料是否真实；CSV 使用 `synthetic=not_declared_by_api`，不能把实际 HTTP 合成数据误标为真实材料。
