## 页面与导出

```powershell

```

页面新增产业链、备忘录和缺来源三种样例，全部虚构，文本由固定协议响应器提供，不是大模型生成或真人金标。连接实际 API 时同一视图读取实际 TaskResult，显示模型候选与审核状态。

- 产业链：按后台节点列出经济主体，分别展示传导方向、机制、情景条件和结论；不把箭头当作已证实因果。
- 备忘录：分开呈现论点、证据陈述、风险、反证/失效条件及跟踪指标。fact 显示“事实性陈述（待核实）”，inference/opinion 保留假设和限制；calculation 明示仍需工具重算。
- 来源按钮只跳转本结果已登记的引用；未知引用提示异常，不发起无关来源请求。沿用固定原件 SHA-256 检查和 PDF/非 PDF 定位区别。
- 跟踪指标的现有契约没有逐项引用字段，明确标注无逐项来源，不能靠页面补出引用或数字。
- 缺资料、空章节保留缺失原因与复核项；不填充伪造论证，也不把空结果视为通过。
- HTML/CSV 保留运行 ID、任务类型、时间、陈述类型、原句、方向、假设、限制、引用、警告与人工复核项；JSON 保持原始 TaskResult，HTML 同时保留完整 JSON。文本进行 HTML 转义和 CSV 公式注入保护。

## 双人标注

```powershell
# 对实际导出的 IndustryData/MemoData TaskResult 生成空白模板；虚构结果须加 --synthetic。
python -m eval.annotations template --result PRIVATE_RESULT.json --dataset DATASET_ID --company 999999 --split holdout --synthetic --output eval/output/semantic-blank.json
python -m eval.annotations combine --first PRIVATE_A.json --second PRIVATE_B.json --adjudications PRIVATE_ADJUDICATIONS.json --output eval/output/semantic-gold.json
```

逐项固定模型输出路径、原句、来源 ID、假设、限制和经济主体上下文；不预填 correct/incorrect/needs_review。声明 ID 绑定公司和 Run，重复模板文本不会跨公司或运行碰撞。两名真人独立填写，分歧由第三人裁决；同人、空标签、上下文被修改或缺裁决仍拒绝导出。

标注 correct 指该表述忠实于来源且保留主体、期间及条件，不代表预测必然兑现或投资结论获准。incorrect 需要明确的来源反证/引用错置/主体混淆等依据；证据不足、范围含糊则 needs_review。金融原文与事实状态仍由 B 核对。工具不能证明填写者是真人或独立完成。

现有 eval.run_eval 的精确率/召回率用于声明纠错判定，不可把 IndustryData/MemoData 直接当作分类预测输入。此轮只交付可人工审阅与裁决的冻结资料，不宣称已取得语义准确率、真实双人金标或公司留出集结果。
