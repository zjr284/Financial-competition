# A/B 模型与语义任务运行说明（2026-10-15）

本轮实现实际 HTTP JSON 调用、语义来源登记、产业链／备忘录运行和固定响应离线重放。现已接通用户选择的阿里云百炼北京地域 `qwen3.7-plus`；真实服务的小范围验收、修正记录和限制见 [千问真实服务验收](千问真实服务验收_20261015.md)。本地协议测试与真实云端调用分别记录，不以连通性代替语义准确率。

## 模型配置

默认保持 offline-rule，只有明确设置后端才联网。当前兼容 chat-completions JSON 协议：temperature=0、非流式、response_format=json_object；返回结果再按本仓库契约校验。参考 [vLLM 官方兼容服务文档](https://docs.vllm.ai/en/stable/serving/online_serving/openai_compatible_server/)，实际供应商仍须验证协议支持。

`qwen3.7-plus` 及其带日期的快照型号额外发送 `enable_thinking=false`，避免默认思考占用当前 4096 Token 输出预算；其他型号不注入该扩展参数。实现依据 [百炼思考模式文档](https://help.aliyun.com/zh/model-studio/deep-thinking)。当前使用用户指定的无日期型号，服务响应也只报告该别名，因此不声称底层权重版本已冻结；固定响应重放仍可验证。非思考模式和 temperature=0 均不保证多次云端生成逐字一致。

在运行服务的同一终端配置真实参数：

```bash
export FINSCOPE_MODEL_BACKEND=remote-json
export FINSCOPE_MODEL_ENDPOINT=https://provider.example/v1/chat/completions
export FINSCOPE_MODEL_ID=实际模型名称
export FINSCOPE_MODEL_REVISION=实际服务或模型版本
# FINSCOPE_MODEL_KEY 通过本机环境配置，不写入仓库或聊天。
```

端点须为完整 HTTP(S) 路径，不含用户名、密码或查询密钥。默认超时 60 秒、最多 2 次尝试；FINSCOPE_MODEL_TIMEOUT_SECONDS 允许大于 0 且不超过 300 秒，FINSCOPE_MODEL_MAX_ATTEMPTS 允许 1—3。仅网络异常、408/429 与指定服务端错误重试；认证失败、非法／截断 JSON、未知引用和 Schema 错误拒绝。响应最多 1 MiB，不跟随重定向，不把供应商原始错误、请求文本或密钥写入公开错误。

health 首次成功调用前显示尚未验证，不因配置存在就宣称连通。离线规则后端明确拒绝生成 IndustryData/MemoData，不再返回错误形状的包装。

## 选择语义来源

先登记解析原件，按真实来源填写披露日；不以报告期或抓取日替代。以下路径与 ID 均为操作人填写的占位参数：

```bash
FINSCOPE_DATA_DIR=PRIVATE_STORE python -m app.cli ingest SOURCE.pdf --source-url OFFICIAL_URL --disclosure-date YYYY-MM-DD --parse
python -m app.facts.review_workflow --data-dir PRIVATE_STORE --manifest PRIVATE_MANIFEST init DOCUMENT_ID
python -m app.facts.review_workflow --data-dir PRIVATE_STORE --manifest PRIVATE_MANIFEST inspect DOCUMENT_ID --contains 原文关键词
python -m app.facts.semantic_sources --data-dir PRIVATE_STORE --manifest PRIVATE_MANIFEST --document-id DOCUMENT_ID --evidence-id EVIDENCE_ID
```

已有清单用 attach 加文档，不能再次 init 覆盖。最后一步仅给私有文档项增加 semantic_evidence_ids；不新增 industry_event 财务指标、不确认 Fact、不写人工复核历史。证据必须属于哈希固定的原件且非空；每文档最多 16 条、每次最多 32 条，每条仅传前 600 字符。原始证据保留在本地，片段仍待分析员复核。

备忘录排除未知或晚于 as_of_date 的披露，以及其他公司的财务事实。IndustryInput 没有截止日字段，本轮不新增公共字段；其资料范围由明确选定的固定包决定，并保留情景条件与限制。

## 运行与重放

```bash
python -m app.tasks.synthesis_runtime --data-dir PRIVATE_STORE --manifest PRIVATE_MANIFEST run --task industry_impact --company COMPANY_CODE --documents DOCUMENT_ID --event 事件描述 --scenarios base
python -m app.tasks.synthesis_runtime --data-dir PRIVATE_STORE --manifest PRIVATE_MANIFEST run --task investment_memo --company COMPANY_CODE --documents DOCUMENT_ID --as-of YYYY-MM-DD
python -m app.tasks.synthesis_runtime --data-dir PRIVATE_STORE --manifest PRIVATE_MANIFEST replay RUN_ID
```

该入口显式装配 B 插件，输出状态、计数、运行 ID 和结果哈希，完整 JSON/HTML 留在私有目录。页面模式可用 demo.live 装配 A/B/C；普通 app.cli 的默认插件范围未扩大，不用其 run/replay 代替上述入口。

模型输入仅保留任务来源字段和临时 ev_model 别名，不发送真实 Fact/Document ID、复核人、复核历史、文档哈希或坐标。返回引用还原后校验，未知别名拒绝。模型不登记金融事实；calculation 声明仍需确定性工具，产业链／备忘录始终保留分析员复核。

每个 Run 的 model-calls 私有目录保存候选输出、版本、输入／输出哈希和调用记录；公开事件只写摘要、版本与哈希。快照绑定原始事件，修改输出并重算文件内部哈希仍被拒绝。重放不新增事件，也绝不在快照缺失时回退到云端。

Run.input_hash 新增绑定模型名与修订号，公共 API 仍为 1.0.0、10 条契约路径。旧运行文件和人工历史不覆盖，历史重放使用相应旧代码。新运行要求代码、模型／提示词版本和来源一致；端点和密钥可以关闭。跨代码版本不能冒称重放一致。

## 验收及后续

全仓 242 项本地测试通过，契约校验通过。成功样例：合成 TXT 经真实解析、显式来源登记和本地 HTTP，返回带引用的 IndustryData/MemoData；固定响应后关闭模型调用仍匹配结果、轨迹与事件链。响应器不是大模型。另有真实 `qwen3.7-plus` 使用公开半年报六条短文本的业务验收，不能扩大解释为整份财报或留出集效果。

pytest 默认隔离开发者的真实模型环境变量；协议测试仅显式配置本机响应器，防止以后配置云端后跑测试意外调用真实服务。

已在隔离工作区组合 PR #8、#10 和本轮实现，251 项 Python 测试通过；该组合仅用于前向兼容验收，不代表这些 PR 已合并。

失败样例：未登记来源返回缺资料；未配置模型返回 MODEL_UNAVAILABLE；401、重复键／非法 JSON、未知引用、截断、错误 Schema 均拒绝；未来披露不送入备忘录；跨文档、哈希不符、响应快照篡改均拒绝。测试入口为 tests/test_model_synthesis_runtime.py。

备忘录提示带内部版本 `memo-economic-subject-v3`，要求保留公司、产品及产业链环节的经济主体，不把客户元器件成本直接归到公司自身成本；反向情景也须由所给来源支撑。所有无引用的备忘录陈述均增加明确复核项，推论和观点同样适用。该提示约束不能替代语义审核，模型结果继续保持 needs_review。
