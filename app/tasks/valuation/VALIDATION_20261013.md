## 实际限制与迁移

真实公司利润、行情、股本和可比性仍需独立复核，本轮未生成正式真实 PE 或真实数据准确率结果。JSON 保留完整结果；CSV/HTML 仍需 C 完成估值专用展示和派生标记验收，文件生成成功不等于展示完成。

计算 ID 新增完整输入及上游来源版本和状态绑定。历史运行不重写，跨代码版本重放可能产生不同 ID 与结果哈希，应使用原代码版本或创建新运行；本版本固定输入与事件轨迹重放已通过。

公共 Fact 可选字段与 Q6 新增端点继续按三方评审流程处理，不阻塞已实现的内部 Calculation 引用路径。
