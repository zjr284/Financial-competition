发布前执行：公开文件中的内部 ID／路径／复核记录扫描；确认私有备份被 Git 忽略；用固定公开 PDF 指定页逐项检查计算输入；Decimal 复算；git diff --check；契约校验。只暂存本次列出的四份研究文件，不使用 git add .。
