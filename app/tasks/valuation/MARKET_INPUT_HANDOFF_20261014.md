## A 的登记与校验入口

app/tools/market_sources.py 以 Decimal 解析数值并检查原生响应结构、唯一记录、公司/交易所、日期、正整数总股本、非复权收盘价一致性和市值勾稽；拒绝重复 JSON 字段、NaN、混入复权序列、错误日期或金额。app/ingest/market_snapshot.py 原样归档 JSON 为 TXT，从精确 $.result.data[0] 路径提取短字段证据，登记 needs_review market_cap。

confidence=1 仅表示精确结构化字段匹配，不表示来源已获人工认可或原件坐标准确。page=1、全页 bbox 是逻辑定位，不能声称为 PDF/OCR 框选。通用 TXT 的解析置信度与人工复核门槛未降低。仅对严格匹配公司/证券市场/交易日/金额/原生数据路径及提供商 URL 的市场观察，估值按观察日用于回溯研究，始终保留首次披露与原始版本未认证的复核提示。普通财报和其他金额未知/晚披露仍排除；不能借此使用未来财报。再次登记同一来源保持已有复核状态，不覆盖真人结论；原始快照变更会产生不同文档/证据/事实版本。

运行入口（路径由操作人按本地资料包填写）：

```bash
python3 -m app.ingest.market_snapshot --data-dir PRIVATE_STORE --manifest PRIVATE_MANIFEST --company 300014 --date 2026-09-30 --primary RAW_PRIMARY_JSON --cross RAW_TENCENT_JSON --output NEW_PRIVATE_RECEIPT_JSON
```

只在清单不存在时初始化，不覆盖已有清单或采用凭据。控制台仅输出状态和凭据哈希；原始字段、定位和源文件保持在私有包。新候选默认待复核，没有自动代签人工确认的参数。

成功技术样例：虚构 999991、收盘 2.5、总股本 100、原始市值 250，日期/代码/勾稽一致，来源检查 consistent、事实仍 needs_review。失败样例：日期错、只有 qfqday、价格不一致、原始市值 251 或小数股数均拒绝；验证失败不修改事实清单。来源定位样例为 JSON 表 $.result.data 第 1 行 TOTAL_MARKET_CAP，TEXT 逻辑页 1；该值可沿固定字节 SHA-256 返回原响应。
